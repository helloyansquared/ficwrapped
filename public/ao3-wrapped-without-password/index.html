Can I get AO3 Wrapped without giving my password?

Yes. AO3 Wrapped tools that run inside your own logged-in browser, such as bookmarklets and extensions, or that read History pages you paste, never receive your AO3 password. Websites, scripts and most Colab notebooks that log in for you do need it. FicWrapped uses a bookmarklet or paste, and its code is public.

How to tell whether a tool wants your login

  • It asks for your AO3 username and password, or for a “session cookie” or “_otwarchive_session” value: it logs in as you.
  • It asks you to log in on a page whose address isn't archiveofourown.org: don't.
  • It runs on AO3 itself while you're logged in, or only reads what you paste: it never sees your password. You're still trusting its code, so prefer tools whose code you can read.

If you already gave a tool your password

Change your AO3 password from your account settings on archiveofourown.org. Changing it means the old password stops working anywhere you gave it.

How FicWrapped does it

The FicWrapped bookmark loads a short script into your AO3 tab. It reads only /users/your-name/readings, about one page a second, and hands the list to the FicWrapped tab you open. Nothing goes to a server. If you'd rather not run code on AO3 at all, paste your History pages instead. The source is on GitHub.

Questions

Is there an AO3 Wrapped that doesn't need my password?

Yes. Tools that run in your own logged-in browser, like bookmarklets and some extensions, or that read History pages you paste, never receive your AO3 password. FicWrapped works both ways. Websites, scripts and most Colab notebooks that log in for you do need it.

Which AO3 Wrapped tools ask for my AO3 password?

Going by their own pages on 26 November 2026: BotHermione Wrapped, teresachenec's ao3wrapped, twitchy-ears' ao3-wrapped and the default mode of nyxbda's Colab notebook ask for your AO3 username and password, and lynx-laurel's AO3 Wrapped 2025 notebook asks for cookie values from your logged-in AO3 page, which lets it read your account as you. The ao3wrapped.vercel.app Chrome extension says it needs neither, and FicWrapped never asks for a password. The two Firefox add-on listings don't say either way, and anulomufa's notebook has a login step whose method isn't described. We haven't tested or audited these tools.

What AO3 Wrapped tools are there?

None are official; all are fan-made. On 26 November 2026 we found a website that logs in for you (BotHermione Wrapped), Python scripts you run yourself (teresachenec's ao3wrapped and twitchy-ears' ao3-wrapped), Colab notebooks (lynx-laurel's AO3 Wrapped 2025, nyxbda's and anulomufa's), browser extensions (ao3wrapped.vercel.app for Chrome, and the AO3-wrapped and AO3+ add-ons for Firefox) and FicWrapped, which uses a bookmark or pasted History pages. The table on our AO3 Wrapped without a password page lists what each one says about passwords, where it runs and phones.

Does FicWrapped need my AO3 password?

No. You log in to AO3 yourself, on AO3, as usual. The bookmark runs in that AO3 tab, reads only your History pages and passes the list to the FicWrapped tab you open. It never sees your password or cookies, and nothing is uploaded to a server.

Is it safe to run a bookmark on AO3?

A bookmark runs code in the AO3 tab, so only use ones you can read. FicWrapped's script is short, published at ficwrapped.yansquared.com/c.js and on GitHub, and it only fetches your own History and Marked for Later list pages, about one a second. It never opens a work, so it can't add works to your History or add hits. FicWrapped is an unofficial fan tool. If you'd rather not run any code on AO3, use the paste option.

Is there an official AO3 Wrapped?

No. AO3 doesn't make a personal year-in-review. Every AO3 Wrapped is fan-made from your AO3 History. FicWrapped is one of them: it reads your History in your own browser and turns it into shareable cards, without asking for your password.
